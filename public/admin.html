      Default penalties

      Used by packs that have no penalties of their own, by Own and as part of Random. One penalty per line.

      Bulk import schema

      Open a pack, then use Import cards. Accepted files: .json or .csv (UTF-8).

      JSON

      {
  "cards": [
    { "title": "Opera Time!",
      "text": "Sing the last message you received as an opera aria.",
      "timeSeconds": 45,
      "info": "Optional explanation shown under the diamond button." },
    { "text": "Invent a new word and use it in three sentences." },
    { "title": "DUO CARD: Same Word!", "text": "Wait until someone draws the matching card...", "duo": true },
    { "title": "DUO CARD: Same Word!", "text": "Wait until someone draws the matching card...", "duo": true }
  ],
  "penalties": ["Do 10 jumping jacks."]
}

      A plain array of cards (or of strings) also works. text is required (max 500 chars). timeSeconds is an optional positive number (max 3600). info is optional (max 1000 chars). title is optional (max 80 chars) and is shown large above the text. duo (true/false) marks a DUO card: DUO cards are meant to come in pairs, so identical DUO cards are kept. Other duplicates (same title and text) are skipped.

      CSV

      type,title,text,timeSeconds,info,duo
card,Opera Time!,"Sing the last message you received as an opera aria.",45,"Read it from your phone.",
card,,Invent a new word and use it in three sentences.,,,
card,DUO CARD: Same Word!,Wait until someone draws the matching card...,,,true
card,DUO CARD: Same Word!,Wait until someone draws the matching card...,,,true
penalty,,Do 10 jumping jacks.,,,

      Header row required; only text is mandatory; title and duo columns are optional, so old files keep working. type is card (default) or penalty. Comma or semicolon separators; wrap values containing commas in double quotes.

      Append adds to existing cards. Replace swaps all cards (and penalties, if the file has any).
